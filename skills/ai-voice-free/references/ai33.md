# ai33.pro — dịch vụ TTS TRẢ PHÍ bên thứ ba (rẻ)

> Mã: `src/voice/ai33.js`. Nguồn: (C) dùng trong production (có server giả để test), tài liệu API của nhà cung cấp tóm tắt 29/09/2026.
> ⚠ **Đây là dịch vụ trả phí của bên thứ ba**, không phải miễn phí. Người dùng tự mua credit và dùng key của chính họ.
> Lợi thế: giá **rẻ hơn mua thẳng** ElevenLabs gốc, một key dùng được nhiều hãng: ElevenLabs, MiniMax, **Vbee (tiếng Việt)**, FishAudio, Kokoro, Edge, giọng clone.
> Đọc điều khoản và bảng giá của ai33 trước khi dùng thương mại.

## Dùng nhanh

```js
const { createAi33 } = require('./src/voice/ai33');
const ai = createAi33();                                    // đọc AI33_API_KEY (hoặc { apiKey })
console.log(await ai.credits());                            // số dư credit
const vbee = await ai.listVoices({ provider: 'vbee' });     // [{ voiceId:'vbee_…', name, lang:'vi-VN', region:'vi-n'|'vi-c'|'vi-s', gender, previewUrl }]
const r = await ai.synthesize({ voiceId: vbee[0].voiceId, text: normalizeVi(text), speed: 1.0 });
fs.writeFileSync('a.mp3', r.buffer);                        // r.words (nếu có transcript), r.durationMs, r.creditCost
```

## API (tóm tắt)

| Việc | Gọi |
|---|---|
| Xác thực | Header `xi-api-key: <KEY>` (v3 cũng nhận `Authorization: <KEY>`, không có "Bearer") |
| Tạo giọng | `POST /v3/text-to-speech` (FormData): `voice_id` (**bắt buộc có tiền tố** `elevenlabs_` / `minimax_` / `clone_` / `edge_` / `kokoro_` / `vbee_` / `fishaudio_`), `text` ≤ 1 000 000 ký tự, `speed` 0,5–1,5, `with_transcript`, tuỳ chọn `receive_url` (webhook), `pronunciation_dictionary_id` → `{ success, task_id, ec_remain_credits }` |
| Chờ kết quả | `GET /v1/task/{id}` → `{ status: doing\|done\|error, progress, error_message, credit_cost, metadata.audio_url … }` |
| Giọng | `GET /v3/voices?provider=…&page=&page_size≤100` (+ `search`, `language`, `gender`, `locale`; Vbee `locale` = northern/central/southern) |
| Số dư | `GET /v1/credits` |
| Khác (chưa có trong mã) | hội thoại nhiều giọng `POST /v3/text-to-speech/dialogue` (`A> B>` + `speakers`), clone giọng `POST /v3/text-to-speech/voice-clone` (→ `clone_<id>`), từ điển phát âm `/v3/dictionaries` |

Rate limit có header `X-RateLimit-*`; 429 kèm `Retry-After`; 503 `server_busy` → thử lại. **Hạn mức tính theo người dùng**: nhiều key của cùng một tài khoản dùng chung hạn mức, xoay key không giúp gì.

## Giọng tiếng Việt

- **Vbee**: giọng Việt bản địa, có vùng miền. `voice_id` thường có tiền tố vùng (`vbee_hn_…` Bắc, `vbee_sg_…`/`hcm` Nam, `vbee_hue_…` Trung) → `region` trong kết quả `listVoices`.
- **ElevenLabs qua ai33**: giọng đa ngữ đọc được tiếng Việt (chất lượng tuỳ giọng). Thư viện ~16 500 giọng (166 trang), nên lọc `search`/`language` ở server.
- **MiniMax / FishAudio**: có giọng đa ngữ; tiếng Việt tuỳ giọng, nghe thử trước.
- **Kokoro** qua ai33: không có tiếng Việt (như bản gốc).
- Danh sách cụ thể thay đổi; luôn lấy bằng `listVoices`, đừng hardcode.

## Bẫy

1. **"Giọng không tồn tại" dù chọn từ danh sách.**
   - Nguyên nhân: `voice_id` gửi đi thiếu tiền tố hãng (danh sách của vài hãng trả id không có tiền tố) (C).
   - Cách tránh: `mapVoice` tự thêm `<provider>_`; `synthesize` từ chối id không có tiền tố với `AI33_VOICE_NOT_FOUND`.
2. **Hết credit báo bằng HTTP 400, không phải 402.**
   - Cách tránh: nhận diện theo nội dung ("Insufficient credits", "not enough", "balance"…) → `AI33_NO_CREDIT` (C).
3. **Bị trừ credit hai lần.**
   - Nguyên nhân: tự gửi lại POST khi mạng rớt giữa chừng, server đã nhận request trước đó.
   - Cách tránh: POST chỉ gửi lại khi 429/503 (chắc chắn chưa nhận). Lỗi mạng → báo `AI33_NETWORK`, để người dùng quyết (C).
4. **Tải danh sách ElevenLabs mất vài phút.** Giới hạn 5 trang cho ElevenLabs (30 cho hãng khác), tải song song 4 trang khi biết `pagination.total`, cache 24 h theo key + bộ lọc (C).
5. **Lọc `language` trả rỗng.** Server không hiểu mã ngôn ngữ → tải lại không lọc rồi lọc tại chỗ (C).
6. **Mốc từ nhiều dạng.** `with_transcript` có thể trả SRT/VTT, mảng `{text,start,end}` (giây hoặc ms), `segments[].words[]`, hoặc alignment ký tự kiểu ElevenLabs, nằm trong metadata hoặc URL riêng. `parseTranscript` xử lý tất cả; đoán ms khi số lớn hơn nhiều so với thời lượng audio (C). Không có mốc từ → `cuesFromText`.
7. **URL audio không an toàn.** Chỉ tải HTTPS (giới hạn 200 MB); preview `http://` bị bỏ (C).
8. **Lộ key.** Không bao giờ log key; người dùng hay dán "xi-api-key: …" / "Bearer …" → `cleanKey` bóc ra. Lưu key mã hoá phía app.

## Chưa kiểm chứng

- Mã trong repo viết lại từ bản production của (C); chưa gọi ai33 thật từ repo này.
- Endpoint dialogue/clone/dictionary: chỉ có trong tài liệu, chưa có mã.
- `speed` của từng hãng: ai33 nhận 0,5–1,5; hãng gốc có thể giới hạn hẹp hơn.
